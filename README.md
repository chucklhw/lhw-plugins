# lhw-plugins

Personal Claude Code plugin marketplace.

## Install

```
/plugin marketplace add chucklhw/lhw-plugins
/plugin install browser-fix@lhw-plugins
/plugin install lhw-skills@lhw-plugins
```

## Plugins

| Plugin | Source | Description |
| --- | --- | --- |
| `browser-fix` | [chucklhw/claude-agent-project](https://github.com/chucklhw/claude-agent-project) | Capture browser console errors and fix them with Claude Code |
| `lhw-skills` | [chucklhw/lhw-skills](https://github.com/chucklhw/lhw-skills) | Personal collection of Claude Code skills by chucklhw |
